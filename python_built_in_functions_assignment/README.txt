PYTHON BUILT-IN FUNCTIONS ASSIGNMENT

Q1. What are built-in functions in Python, and why are they important?
Built-in functions are functions already provided by Python. They are important because they perform common tasks quickly and make programs shorter and easier to write.

Q2. How can you list all built-in functions available in Python?
Use:
print(dir(__builtins__))

Q3. What is the purpose of print() and input()?
print() displays output on the screen.
input() receives input from the user as text.

Q4. Difference between int(), float(), str(), bool(), and list()
int() converts a value to an integer.
float() converts a value to a decimal number.
str() converts a value to text.
bool() converts a value to True or False.
list() creates or converts a value into a list.

Q5. How do min(), max(), sum(), abs(), and round() work?
min() returns the smallest value.
max() returns the largest value.
sum() adds values together.
abs() returns the positive distance from zero.
round() rounds a number to a specified number of decimal places.

Q6. Difference between pow() and ** operator
pow(a, b) and a ** b both calculate a raised to the power b.
pow() can also accept a third argument for modular exponentiation.

Q7. How do len(), sorted(), and reversed() work with lists?
len() returns the number of elements.
sorted() returns a new sorted list.
reversed() returns the elements in reverse order.

Q8. Difference between zip() and enumerate()
zip() combines elements from two or more iterables.
enumerate() gives both the index and value while looping.

Q9. Difference between id() and type()
id() returns an object's identity.
type() returns the type or class of an object.

Q10. How does dir() help explore Python objects?
dir() lists the available attributes and methods of an object.
