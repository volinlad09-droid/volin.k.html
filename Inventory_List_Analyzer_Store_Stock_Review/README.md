# Inventory List Analyzer – Store Stock Review

## Run
```bash
python inventory_list_analyzer.py
```

## Concepts used
- while/for loops
- if/else conditions
- string handling: strip(), lower(), join(), title()
- list of dictionaries
- dictionary mapping item names to quantities
- set for unique categories
- built-in functions: sum(), max(), min(), sorted(), len(), enumerate()
- substring search
- sorting by quantity and category
