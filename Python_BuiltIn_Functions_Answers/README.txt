PYTHON BUILT-IN FUNCTIONS - ANSWERS

1. sorted() sorts a list. reverse=True gives descending order.
   reversed() returns items in reverse order.

2. dir(__builtins__) can be used to explore available built-in names.

3. print() displays output. input() receives input from the user.

4. int() converts to integer.
   float() converts to decimal/float.
   str() converts to text.
   bool() converts to True or False.
   list() converts an iterable into a list.

5. min() gives the smallest value.
   max() gives the largest value.
   sum() adds values.
   abs() gives absolute value.
   round() rounds a number.

6. pow(a, b) and a ** b calculate powers.
   pow(a, b, c) can also calculate the result modulo c.

7. len() gives the number of items.
   sorted() returns a sorted list.
   reversed() returns items in reverse order.

8. zip() combines corresponding items from iterables.
   enumerate() provides an index and value while looping.

9. id() gives an object's identity.
   type() gives an object's data type.

10. dir() lists attributes and methods available for an object.
