# PR. 4 - Functional Treat

A Python classroom project for analyzing student marks.

## Requirements covered
- 20 student scores in a 1D list
- `len()`, `max()`, `min()`, `sum()`
- Passed and failed students
- Exact score of 100
- Pass percentage
- Ascending and descending sorting with `sorted()`
- Grade A and Grade B counts using `filter()` / lambda
- No NumPy or external libraries

## Run
```bash
python functional_treat.py
```
